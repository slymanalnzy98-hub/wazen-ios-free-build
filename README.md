# WAZEN iPhone Free Build

Public build-only wrapper for the personal WAZEN iPhone app.

This repository intentionally contains only the minimal native iOS shell needed to:
- open the production WAZEN web app at https://wazen-personal.onrender.com/
- read today's iPhone steps with Core Motion / CMPedometer
- build an unsigned IPA with GitHub Actions

It does not contain the private WAZEN application source, backend code, credentials, user data, HealthKit integration, or secrets.

Generated artifact: `WAZEN-Free-iPhone-V1-unsigned-IPA`

IPA file: `WAZEN-Free-iPhone-V1-unsigned.ipa`
